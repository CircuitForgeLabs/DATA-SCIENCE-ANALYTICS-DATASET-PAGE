📘 For the Instructor — How to add files to the shared library

GitHub Pages cannot accept uploads from a webpage. To add a new dataset everyone can download:

  1. Put the Excel file in the same folder as index.html.
  2. Add a new entry to the DATASETS array inside the <script> tag of this file.
  3. Commit and push to GitHub:
git add .
git commit -m "Add new dataset"
git push origin main

The dataset appears in the shared library within seconds of the GitHub Pages deploy.
